# Split Proxy Windows 0.1.1

Windows-клиент Split Proxy для Windows 10/11 x64.

## Что реализовано

- C# / .NET 10 / WPF, self-contained: конечному пользователю не нужен отдельно установленный .NET.
- Один экземпляр приложения: повторный запуск ярлыка открывает уже работающий экземпляр.
- Закрытие окна скрывает интерфейс и оставляет приложение в системном трее.
- Правый клик по значку → **Выйти из приложения** завершает UI и отключает маршрутизацию.
- Windows-служба `SplitProxyService` управляет нативным сетевым движком.
- Логин/регистрация и активация `platform=windows` через `split-proxy.ru/api/v1`.
- Выбор EXE; браузеры запрещены в UI и повторно фильтруются службой.
- Windows получает только SOCKS5-маршруты от `devices/proxy/config`.
- SOCKS5 username/password поддерживается для TCP CONNECT и UDP ASSOCIATE.
- Токены, ключи и состояние с proxy credentials защищаются Windows DPAPI.
- SOCKS5 password не записывается в JSON-конфиг нативного route engine: служба передаёт его дочернему процессу через environment.
- Проверка обновлений при запуске и далее каждые 2 часа.
- Обновление: скачать Setup.exe → обязательно проверить SHA-256 → закрыть UI → UAC → обновить → снова запустить приложение.
- Нативный selective router: `wfp-divert` + WinDivert 2.2.2.

## Серверная схема NL

Контроллер выдаёт sticky-маршрут между всеми healthy entry-node. На текущем сервере подготовлены:

- RF1 `195.209.208.251:29443` SOCKS5 → ND;
- RF2 `185.182.65.233:29443` SOCKS5 → ND.

Выбор стабилен для конкретного устройства и автоматически исключает unhealthy route.

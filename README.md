# Split Proxy Windows 0.1.0

Windows-клиент Split Proxy для Windows 10/11 x64.

## Что уже заложено

- C# / .NET 10 / WPF.
- Self-contained публикация: на клиентском ПК не нужен установленный .NET.
- Один экземпляр приложения: повторный запуск ярлыка открывает уже работающий экземпляр.
- Закрытие окна скрывает интерфейс, но программа остаётся в системном трее.
- Правый клик по значку в трее → **Выйти из приложения** полностью завершает UI и отключает маршрутизацию.
- Отдельная Windows-служба `SplitProxyService` держит сетевой движок независимо от открытого окна.
- Логин/регистрация через `split-proxy.ru/api/v1`.
- Активация Windows-устройства: `install_id` + ECDSA P-256 + P1363 подпись.
- Device token и account token защищены Windows DPAPI для текущего пользователя.
- Выбор EXE; известные браузеры блокируются в UI и повторно фильтруются службой.
- Проверка обновлений через `/api/v1/apps/version` при запуске и каждые 2 часа.
- Обновление: скачать Setup.exe → проверить SHA-256 (если сервер отдаёт) → закрыть UI → запустить установщик с UAC → обновить → снова запустить Split Proxy.
- Нативный маршрутизатор TCP/UDP: MIT `wfp-divert` + WinDivert 2.2.2, управляется Windows-службой.

## Важное условие сетевой части

Windows-клиент специально принимает только `SOCKS5` от серверного `devices/proxy/config`. Это сделано, чтобы TCP и UDP выбранного приложения не уходили напрямую. Если сервер выдаёт `http`/`https`, клиент не включает маршрутизацию и показывает ошибку.
